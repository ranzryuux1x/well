CHIKAMD FULLCOMBINED - CONTINUATION & COMPLETE INTEGRATION

Lanjutkan pengembangan project ChikaMD-FullCombined yang sudah tersedia di workspace saat ini.

TUJUAN UTAMA

Lakukan audit dan integrasi ulang terhadap 3 project sumber:

1. Hoshino AI
2. vanXone V4
3. Kaguya Multi Device V5
   Hasil sebelumnya bernama ChikaMD-FullCombined, tetapi integrasinya belum lengkap. Jangan menganggap project tersebut sudah selesai hanya karena file berhasil digabungkan.
   TARGET: Menghasilkan satu project ChikaMD yang mengintegrasikan fitur penting dari ketiga project sumber tanpa kehilangan fungsi, konflik kode, atau duplikasi yang tidak diperlukan.

- Database dan sistem penyimpanan.
- Handler dan command system.
- Downloader dan scraper.
- Sistem RPG.

- Dependencies dan package.
- File konfigurasi.

  Jangan hanya mencocokkan nama file. Periksa isi kode, fungsi, dependensi, dan keterkaitan antarmodul.

5. ARSITEKTUR FINAL

Hasil akhir harus tetap menjadi SATU PROJECT bernama ChikaMD.
Ketentuan:

- Gunakan satu sistem startup.
- Gunakan satu sistem konfigurasi utama.
- Gunakan satu package.json utama.
- Gunakan satu sistem plugin yang terintegrasi.
- Gunakan satu sistem database utama jika memungkinkan.
- Hindari duplikasi engine.
- Hindari fungsi dengan nama sama tetapi perilaku berbeda tanpa penyelesaian konflik.
- Gunakan CommonJS secara konsisten.
- Jangan membuat file .mjs atau sistem ESM.
- Jangan membuat project tambahan yang berdiri sendiri.
  Jika modul memiliki arsitektur berbeda, buat adapter atau compatibility layer agar bisa digunakan tanpa merusak implementasi asli.

6. KOMPATIBILITAS

Pastikan:

- Modul lama tetap dapat dipanggil.
- Plugin lama tidak rusak.
- Import dan export sesuai.
- Path file benar.
- Event listener tidak terdaftar berulang.
- Tidak ada konflik nama command.
- Tidak ada circular dependency yang menyebabkan kegagalan.
- Sistem WhatsApp multi-device tetap berfungsi.
- Modul Telegram tidak mengganggu WhatsApp.
- Dependencies tidak saling bertabrakan.
  Jangan mengubah seluruh kode secara massal hanya demi menyamakan gaya penulisan.

7. OPTIMASI

Optimalkan:

- Ukuran project.
- Penggunaan RAM.
- Waktu startup.
- Penggunaan CPU.
- Pemanggilan modul.

ATURAN PENGERJAAN

- Jangan berhenti setelah membuat rencana.
- Jangan hanya membuat struktur folder.
- Langsung kerjakan integrasi source code.
- Jangan meminta konfirmasi untuk setiap perubahan teknis yang aman dan dapat dibatalkan.
- Jangan menghapus source project asli.
- Jangan menghapus fitur yang belum dipahami.
- Jangan membuat implementasi palsu atau placeholder untuk mengklaim fitur selesai.

KRITERIA SELESAI

ChikaMD hanya boleh dinyatakan selesai apabila:

1. Ketiga project sudah diaudit.
2. Seluruh fitur relevan sudah diintegrasikan.
3. Tidak ada kehilangan fitur penting yang tidak dijelaskan.
4. Seluruh modul utama kompatibel.
5. Syntax dan import valid.
6. Testing berhasil sesuai kemampuan lingkungan.
7. Hasil akhir tetap satu project ChikaMD.
